# Local Service Finder - Project Architecture

A small full-stack web application where people can find local service providers (tailors, electricians, tutors, plumbers) and leave reviews.

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- Database: MongoDB

## Folder Structure
- `client/` - React frontend
- `server/` - Express API
- `docs/` - Architecture document
